# BMP Watermark

Учебный проект на C++ для наложения водяного знака на BMP-изображение.

## Возможности

- Чтение и сохранение 24-битных BMP-изображений.
- Хранение и изменение пикселей через класс `BMPImage`.
- Предусмотрены параметры водяного знака: координаты `posX`, `posY` и коэффициент смешивания `alpha`.

## Структура проекта

- `lib/` — класс `BMPImage` и функции обработки изображений.
- `bin/` — точка входа в программу.
- `input/` — пример изображения `Car.bmp` и файл настроек `settings.ini`.
- `docs/` — документация.

## Сборка

Требуются CMake 3.10 или новее и компилятор Clang с поддержкой C++23.
Команды выполняются из корня `BMP_watermark`:

```sh
cmake -S . -B build
cmake --build build
```
